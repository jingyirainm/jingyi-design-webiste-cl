Overview & Context

Connect ideas, plans, files, and learning in one creative flow.

A designer may save a reference on Instagram, write a thought in Notes, plan the week in a calendar, track tasks in another app, and export the final file into a folder. Each tool works on its own. The problem appears between them. Context disappears during every handoff, and the creator must rebuild the story of the work from memory.

Knotboard brings that story into one connected workspace. A reference can become a task. A task can belong to a project, appear in the weekly plan, move onto a calendar, produce a deliverable, and return to the dashboard as evidence for reflection. The product keeps the source, action, output, and learning connected.

The Problem

Creative work fails when ideas and execution stay disconnected.

Imagine a design student named Maya. On Monday, she saves a typographic poster because of its unusual grid. On Tuesday, she finds a material experiment in a gallery archive. By Friday, both references are buried under newer images. When she begins her own project, she remembers that she found something useful, but not where it came from or why it mattered.

The missing feature is not another bookmark. Maya needs a path from recognition to action. She needs to record the reason a reference matters, connect it to a project, and decide what to do with it while the thought is still fresh.

The opportunity

The product opportunity was to treat creative work as a connected cycle instead of a set of isolated lists. Inspiration should carry its context forward. Planning should be flexible enough for exploratory work. Completion should recognize output without forcing every task to produce a file. Review should turn activity into an informed next step.

User Research

Different roles share the same broken handoffs.

Knotboard focuses first on individual creators, but the system was designed around needs that also appear in fast-moving content work and design teams. The details change by role; the underlying job remains consistent: keep ideas, commitments, and evidence of progress connected.

These behaviors led to a central design principle: Knotboard should reduce the cost of moving from one stage of work to the next. The system should remember the relationships so the user can keep thinking about the work itself.

Design Decisions

Five product decisions turned the connected loop into a working system: capture, plan, organize, review and assist.

01 · Capture First

Capture first, organize when the idea has a future.

The Inspiration library is the product’s front door. It accepts the messy forms in which ideas actually arrive: a URL, an image, a sentence, a PDF, or another file. The capture field stays prominent and lightweight because adding a reference should not require a classification decision first.

Why the library behaves differently from a folder

Knotboard stores more than files—it preserves why each reference matters and what it could become. Users can organize items, connect them to projects, and turn them into tasks without losing context. Compact URL cards, visual-first image cards, and hidden drag controls keep the library flexible and uncluttered.

Inspiration Library Function
  • Capture thoughts, images, links, PDFs, and other references in one place.
  • Organize inspiration with tags, collections, projects, and research topics.
  • Turn any reference directly into a task or project—moving ideas into action.

02 · Plan with Shape, Not Certainty

A plan should give shape to the week without pretending every task is predictable.

Creative work contains different kinds of effort. Some tasks are routine and easy to estimate. Others are uncertain because the creator is still learning what the problem is. Knotboard makes that difference visible without turning planning into a scoring exercise.

One task, several useful views

Planner, Calendar, Tasks, and Project pages do not create separate copies of a task. They show the same record from different angles. The Planner supports weekly intent. Calendar handles dated work and a backlog. Tasks provides a searchable operational list. Projects preserve context and history. Editing status, due date, estimate, or assignment in one view updates the same underlying task everywhere.

Planner Function
  • Create task cards within each project to build a clear action plan.
  • Set priority, difficulty, output value, and estimated time; Knotboard converts them into an XP score.
  • Drag and reorder tasks for a fast, flexible planning experience.
  • Use clear visual states to understand progress at a glance.
Tasks Function
  • View every task across projects and channels in one structured list.
  • Filter by status, project, channel, assignee, priority, or due date.
  • Find the right task quickly and manage complex workflows efficiently.
Calendar Function
  • Drag unscheduled tasks from Backlog directly onto the calendar.
  • Switch between day, week, and month views to plan at different levels.
  • See workload and deadlines in one clear timeline.

03 · Keep Work and Evidence Together

The project page keeps the work and the evidence together.

A creative project is more than a task list. It has a reason, a body of research, a changing plan, and artifacts that show what was made. Knotboard’s Channel and Project structure keeps those layers in one place without forcing every project into the same template.

Channels create a stable map

Channels organize the larger areas of a creative practice. Each channel contains projects. Each project can hold its own tasks, inspiration, description, link, cover, status, and deliverables. This structure lets a user zoom from a long-term area of growth to the exact task that needs attention today.

Deliverables make progress visible

When a task produces an image, document, link, or other output, the result appears in the project’s Deliverables gallery. The gallery is both practical and motivational: it creates a visual record of work that would otherwise vanish into folders. Because deliverables are optional, the system respects tasks whose value is learning, deciding, communicating, or exploring.

Points reward effort without replacing judgment

Points translate task difficulty, importance, output value, and time into a lightweight signal. They help users compare commitments and recognize effort. They are not a quality score. The product pairs them with the actual deliverable and a written reflection so progress is never reduced to a number.

Channel & Project Function
  • Organize projects by channel with customizable covers, layouts, and visuals.
  • Keep project details, tasks, references, progress, and outputs connected.
  • Showcase finished work in a rewarding Deliverables Gallery and XP Board.
  • Review every scheduled task within the full project context.

04 · Completion Informs the Next Plan

Completion becomes useful when it changes the next plan.

Most productivity tools treat completion as the end of the story. Knotboard treats it as evidence. The Dashboard gathers completed tasks, time, points, project status, deliverables, and review notes into one place. A global time filter keeps the period consistent across charts so users do not have to reconcile daily, weekly, monthly, and overall views by hand.

Dashboard Function
  • Turn a complex workload into measurable progress.
  • Track completed tasks, focused hours, earned points, and project performance.
  • Use clear charts and trends to understand what happened—and decide what to do next.

05 · Agent Where Context Exists

AI Agent appears where context already exists.

Knot Agent is not a separate chatbot pasted onto the product. Its usefulness depends on the workspace around it: saved references, unfinished tasks, project priorities, dates, estimates, deliverables, and review history. The agent can make a relevant suggestion because Knotboard has preserved the context of the work.

Reflection

Designing the system changed how I define productivity

At the start, Knotboard could have become a larger to-do list. The research framing and product structure pushed it in a different direction. Creative productivity depends on preserving meaning across time. The reference that sparked the work, the decision that shaped the plan, the effort required to make it, and the lesson discovered afterward all belong to the same story.

The project strengthened my ability to work across product strategy and visual design. Information architecture made the system coherent. Interaction design made the handoffs usable. The visual language made a dense workspace feel calm. Brand thinking gave the product a clear point of view. AI design added a new constraint: assistance is valuable only when it uses context responsibly and keeps the user’s judgment visible.
